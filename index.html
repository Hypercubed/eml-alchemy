How it works

  • Keys work on a stack, like an RPN calculator. Values (1, x, y, digits) land on the stack and an operation uses the top of it. No brackets needed.
  • Operations take values in the order you entered them: 1 1 eml is 1 eml 1, and x y − is x − y.
  • There is no equals key. The moment a result behaves like a standard calculator key, that key unlocks. x and y stand for any number, so results are tested at many values, not only the ones in the boxes.
  • dup copies the top value and swap exchanges the top two. Undo steps back one key.
  • Dashed keys are still locked. Tap one for a hint.
